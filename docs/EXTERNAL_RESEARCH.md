# Pesquisa externa — candidatos avaliados

Esta vertical slice prioriza coerência visual e zero dependência em runtime. Durante a preparação foram avaliados recursos externos adicionais:

- Kenney RPG Base — pacote 2D CC0, forte candidato para UI/objetos neutros em uma futura rodada de direção de arte.
- Kenney Isometric Dungeon Tiles — CC0, candidato para ampliar a biblioteca de dungeon caso a direção final aceite a linguagem isométrica do pacote.
- `javascript-astar` (GitHub, MIT) — implementação A* de referência. Não foi adicionada porque as quatro atividades atuais usam rotas controladas e a vertical slice não precisa de dependência externa para pathfinding.

Decisão: não misturar novos packs apenas por disponibilidade. O projeto usa, nesta etapa, os materiais recebidos que já encaixam no visual e/ou nos sistemas. Isso mantém a autoria do layout e evita que a cena vire um mosaico de estilos desconectados.
