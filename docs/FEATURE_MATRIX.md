# Feature Matrix

| Sistema | Estado | Observação |
|---|---|---|
| Mundo central renderizado | Funcional | Vila, floresta, dungeon, boss |
| Heróis visíveis | Funcional | 4 heróis animados/fallback |
| Auto attack | Funcional | Timer + seleção de alvo |
| Skills manuais | Funcional | Q/W/E/R |
| Auto skills | Funcional | Decisão por cooldown/HP |
| HP / MP / cooldown | Funcional | HUD + simulação |
| Crit / dodge / defense | Funcional | Fórmulas no engine |
| Buff/debuff/status | Funcional | Burn, stun, armor break, regen |
| Dungeon | Funcional | 5 salas + escolha de rota |
| Boss | Funcional | 3 fases + AoE |
| Loot | Funcional | raridade + drop físico + inventário |
| EXP / level up | Funcional | herói e conta |
| Equipamento | Funcional | weapon/focus/trinket |
| Consumíveis | Funcional | HP/MP |
| Crafting | Funcional | 3 receitas iniciais |
| Construções | Funcional | 4 prédios com upgrade |
| Missões | Funcional | 5 objetivos |
| Passe | UI/progressão | trilha desenhada; compra real não implementada |
| Guilda | Funcional local | contribuição/nível; sem backend multiplayer |
| Save | Funcional | localStorage |
| Offline progress | Funcional | até 8h |
| Multiplayer real | Não incluído | exige backend/autenticação |
| Pagamentos | Não incluído | exige provedor e backend |
| Arte autoral final | Pendente | proxies licenciados nesta vertical slice |
